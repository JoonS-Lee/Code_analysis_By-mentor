PHASE 1 소스코드 업로드

분석 대상 MCU 펌웨어 C 소스파일(.c / .h / .txt)을 업로드하거나, 코드를 직접 붙여넣으세요. EUC-KR / UTF-8 인코딩을 자동으로 인식합니다. (모든 처리는 브라우저 내부에서만 수행되며 코드가 외부로 전송되지 않습니다)

PHASE 2 소스코드 구조 분석

업로드된 소스코드의 함수·상수·조건 분기·호출 관계를 자동으로 추출한 결과입니다. 기능 카테고리를 선택하거나 함수명을 클릭하면 상세 분석(제어 조건, 플로우차트)을 확인할 수 있습니다.

PHASE 3 기능 사양서(Draft) 문서화

분석된 로직을 표준 양식(표지 → 개정 이력 → 1. 기능 목적 → 2. 시스템 구성부품 → 3. 주요 기능 정의)에 맞춰 Word 문서로 자동 작성합니다. 각 기능 영역별로 입출력 List, 작동 워크플로우, 서브 기능 표기, CAN 사양, 관련 파라미터가 포함됩니다.

※ 생성된 문서는 Draft(초안)입니다. 차종명, 담당자, 관련 법규 등 프로젝트 특화 항목은 문서 내 [확인 필요] 표시를 참고하여 실무 검토 후 확정하세요.

PHASE 4 교차 검증

작성된 사양서의 각 항목이 실제 소스코드의 어느 함수·라인에 근거하는지 자동으로 대조한 결과입니다. 근거가 확인된 항목은 ✔, 소스에서 직접 확인되지 않아 실무 검토가 필요한 항목은 ⚠ 로 표시됩니다.
